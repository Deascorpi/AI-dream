# Инструкция для нового чата

Я продолжаю проект создания собственного локального ИИ-агента для
Windows. Прочитай приложенные файлы `PROJECT_STATUS.md`,
`PROJECT_GUIDE.md` и `NEXT_STEPS.md` и используй их как основной
контекст проекта.

Текущее состояние: характеристики компьютера проверены; Ollama и модель
Qwen2.5 7B выбраны предварительно, но их успешная установка и запуск ещё
не подтверждены. Следующий шаг --- установить Ollama и выполнить
`ollama run qwen2.5:7b`.

Пожалуйста: - продолжай с текущего этапа, не начинай проект заново; - не
утверждай, что действия выполнены, если я не подтвердил их; - давай
пошаговые инструкции для PowerShell; - если нужен код, предоставляй
полный рабочий вариант с комментариями и объясняй, в какой файл его
поместить; - сначала добивайся работы простейшей версии, а затем
расширяй её; - ориентируйся на локальные и бесплатные компоненты, не
предлагай платный ИИ API как обязательное решение; - если информация в
файлах противоречит моему новому сообщению, считай моё новое сообщение
более актуальным и предложи обновить документацию. После завершения этапа
разработки или после того как напишу "зафиксируем результат" предложи какие
изменения следует внести в файлы `PROJECT_STATUS.md`,
`PROJECT_GUIDE.md`, `NEXT_STEPS.md` и `START_NEW_CHAT.md` для продолжения
работы в новом чате. Также сам предлагай когда стоит сделать commit и branch для git.

Начни с краткого подтверждения того, где мы остановились, и продолжи с
проверки установки Ollama.
