## Цель проекта

Создать собственного персонального ИИ-агента, который работает
преимущественно на компьютере пользователя под Windows и использует
локальную языковую модель, чтобы не платить за облачный ИИ API.

В перспективе агент должен: - принимать команды текстом и голосом; -
понимать намерение пользователя и планировать действия; - открывать
сайты и выполнять разрешённые действия в браузере; - постепенно получать
инструменты для работы с файлами и программами Windows; - сообщать о
результате выполнения; - в будущем принимать команды с Android-телефона,
отправляя их на домашний компьютер.

## Ближайшая задача

1.  Установить Ollama для Windows с официального сайта:
    https://ollama.com/download/windows
2.  В PowerShell выполнить: `ollama run qwen2.5:7b`
3.  Дождаться загрузки модели и проверить, отвечает ли она на русском
    языке.
4.  Выйти из чата сочетанием `Ctrl+C`.
5.  Выполнить `ollama list` и, при необходимости, `nvidia-smi`.
6.  Сообщить результат в чат, чтобы перейти к созданию простого
    Python-агента.
